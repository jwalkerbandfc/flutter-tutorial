Game Entities

Time to make good on that "the actual game world arrives in Module 4!" placeholder from last time. We're going to build the things that actually live inside a game: a Player, some Obstacles, and a scrolling Background. Each one gets its own class, following exactly the pattern GameSession taught us in Module 3 — self-contained data, with a method that hands back something Flutter can draw.

1. What's a Game Entity?

An entity is just a fancy word for "a thing that exists in the game world." The player is an entity. Every obstacle is an entity. Even the background counts. Each one needs, at minimum, a position and a way to draw itself.

Analogy: remember the vending machine from Module 3 — an object hides its data and only lets you interact through its buttons? Entities work the same way. A Player object will know its own x and y position and have a build() method that draws itself. Nothing outside the class needs to know how it draws itself — just that it can.

2. Drawing With CustomPaint: A Digital Etch-a-Sketch

So far every visual we've made has been built from ready-made widgets — Text, Icon, Container. For actual game art, we often want to draw exact shapes ourselves. That's what CustomPaint is for.

Analogy: a CustomPaint widget hands you a blank sheet — the Canvas — and a pen with an ink color you choose — the Paint. You then give exact instructions: "draw a circle here, this big, in this color." There's no pre-made picture involved; you're describing the shape with math (coordinates and sizes) instead of loading a file.

A CustomPaint widget needs a painter — a class extending CustomPainter with a paint(Canvas canvas, Size size) method, where you call things like canvas.drawOval() or canvas.drawRect(). It also needs a shouldRepaint() method, which tells Flutter whether to redraw when something changes — we'll return false for now, since nothing's moving yet. That changes in Module 5.

/// The player character — an entity with a position and a way to draw itself.
class Player {
  double x;
  double y;
  final double size;

  Player({required this.x, required this.y, this.size = 50});

  Widget build() {
    return Positioned(
      left: x,
      top: y,
      child: CustomPaint(
        size: Size(size, size),
        painter: _PlayerPainter(),
      ),
    );
  }
}

class _PlayerPainter extends CustomPainter {
  @override
  void paint(Canvas canvas, Size size) {
    final body = Paint()..color = Colors.orange;
    canvas.drawOval(Rect.fromLTWH(0, 0, size.width, size.height), body);

    final eye = Paint()..color = Colors.black;
    canvas.drawCircle(Offset(size.width * 0.68, size.height * 0.35), 4, eye);
  }

  @override
  bool shouldRepaint(covariant CustomPainter oldDelegate) => false;
}

Notice Player isn't a widget at all — it's a plain Dart class holding x and y, with a build() method that returns a Positioned widget. Positioned only works directly inside a Stack, and it pins its child an exact distance from the edges you specify (here, left and top) rather than centering it.

3. Stacking Layers: Overhead Projector Transparencies

Analogy: think of a Stack like a pile of transparent sheets on an overhead projector. Each sheet (each child) sits directly on top of the one before it, and you can see through the gaps to whatever's underneath. The background goes on the bottom sheet, obstacles go on the next sheet up, the player goes above that, and the score text sits on the very top sheet.

Example 2: Adding an Obstacle

Now let's add something for the player to avoid. Obstacle follows the exact same pattern as Player — its own class, its own painter, its own build() method — proof that once you've learned the entity pattern once, every new game object is the same shape of work.

class GameScreen extends StatelessWidget {
  final GameSession session;

  const GameScreen({super.key, required this.session});

  @override
  Widget build(BuildContext context) {
    final player = Player(x: 40, y: 240);
    final obstacle = Obstacle(x: 260);

    return Scaffold(

      body: SizedBox.expand(
        child: Container(
          color: Colors.lightBlue.shade200,
          child: Stack(

              player.build(),
            ],
          ),
        ),
      ),
    );
  }
}

/// An obstacle the player has to avoid — same entity pattern as Player.
class Obstacle {
  double x;
  final double width;
  final double height;

  Obstacle({required this.x, this.width = 40, this.height = 140});

  Widget build() {
    return Positioned(
      left: x,
      bottom: 0,
      child: CustomPaint(
        size: Size(width, height),
        painter: _ObstaclePainter(),
      ),
    );
  }
}

class _ObstaclePainter extends CustomPainter {
  @override
  void paint(Canvas canvas, Size size) {
    final paint = Paint()..color = Colors.green.shade700;
    canvas.drawRect(Rect.fromLTWH(0, 0, size.width, size.height), paint);
  }

  @override
  bool shouldRepaint(covariant CustomPainter oldDelegate) => false;
}

Order matters inside children: obstacle.build() is listed before player.build(), so the obstacle sits on a lower "sheet" and the player is drawn on top of it — useful once we add collision detection in Module 5 and want the player clearly visible.

4. External Images: A Photo From a Link

A flat blue rectangle works, but it's not much of a sky. DartPad runs entirely in your browser and can't read image files from your computer, so instead of bundling artwork with the app, we load it from a URL on the internet using Image.network.

Analogy: back in Module 2 we compared a StatelessWidget to a printed photograph — fixed once it's made. Image.network is more like showing someone a photo through a link instead of a physical print: Flutter fetches it from the address you give it every time the app runs, rather than storing a copy inside the app itself.

Image.network takes a URL and, optionally, a fit — we'll use BoxFit.cover, which scales the image to completely fill its space, cropping the edges if it doesn't match the exact proportions.

In your own project: once you leave DartPad and build a real Flutter app (back in Android Studio from Module 1), you can instead bundle proper local artwork using an assets: section in pubspec.yaml and Image.asset() — much more reliable than depending on an internet connection. We're using Image.network here purely because DartPad has no way to reach local files.

import 'package:flutter/material.dart';

void main() {
  runApp(const GameMenuApp());

/// Holds the game's data and rules — no widgets, no UI, just logic.
class GameSession {
  int _score = 0;
  int _lives = 3;

  int get score => _score;
  int get lives => _lives;
  bool get isGameOver => _lives <= 0;

  void addPoint() {
    _score++;
  }

  void loseLife() {
    if (_lives > 0) {
      _lives--;
    }
  }
}

class GameMenuApp extends StatelessWidget {
  const GameMenuApp({super.key});

  @override
  Widget build(BuildContext context) {
    return MaterialApp(
      title: 'Game Menu',
      theme: ThemeData(useMaterial3: true, primarySwatch: Colors.indigo),
      home: const MenuScreen(),
    );
  }
}

class MenuScreen extends StatefulWidget {
  const MenuScreen({super.key});

  @override
  State createState() => _MenuScreenState();
}

class _MenuScreenState extends State {
  final GameSession _session = GameSession();

  void _addPoint() {
    setState(() {
      _session.addPoint();
    });
  }

  void _openGameScreen() {
    Navigator.push(
      context,
      MaterialPageRoute(builder: (context) => GameScreen(session: _session)),
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Sky Runner')),
      body: Padding(
        padding: const EdgeInsets.all(24.0),
        child: Column(
          mainAxisAlignment: MainAxisAlignment.center,
          crossAxisAlignment: CrossAxisAlignment.center,
          children: [
            const Text(
              'Welcome, Player!',
              style: TextStyle(fontSize: 28, fontWeight: FontWeight.bold),
            ),
            const SizedBox(height: 24),
            Container(
              padding: const EdgeInsets.symmetric(horizontal: 20, vertical: 12),
              decoration: BoxDecoration(
                color: Colors.indigo.shade50,
                borderRadius: BorderRadius.circular(12),
              ),
              child: Row(
                mainAxisSize: MainAxisSize.min,
                children: [
                  const Icon(Icons.favorite, color: Colors.red),
                  const SizedBox(width: 8),
                  Text('Lives: ${_session.lives}', style: const TextStyle(fontSize: 18)),
                  const SizedBox(width: 24),
                  const Icon(Icons.star, color: Colors.amber),
                  const SizedBox(width: 8),
                  Text('Score: ${_session.score}', style: const TextStyle(fontSize: 18)),
                ],
              ),
            ),
            const SizedBox(height: 32),
            ElevatedButton(
              onPressed: _addPoint,
              child: const Text('Tap to score a point!'),
            ),
            const SizedBox(height: 16),
            OutlinedButton(
              onPressed: _openGameScreen,
              child: const Text('Play'),
            ),
          ],
        ),
      ),
    );
  }
}

class GameScreen extends StatelessWidget {
