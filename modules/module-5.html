The Game Loop

Everything on screen right now is frozen — a nice picture, but not a game. This final module fixes that. We're going to make the world move on its own, give the player gravity and a jump, and detect when they crash into something. By the end, you'll have a real, playable game running entirely in your browser.

1. The Flipbook, For Real This Time

Back in Module 2 we mentioned that a game is really just setState() being called over and over, automatically, many times a second. That's the whole secret. A "game loop" is just something that keeps calling a function on a timer, forever, and each call nudges every entity's position a tiny bit before redrawing.

Analogy: a flipbook only looks like it's moving because you flip through dozens of nearly-identical drawings really fast. Nothing on any single page moves — your eye just can't tell the difference between "the ball moved" and "a new picture with the ball slightly further along" flashed past you fast enough. A game loop does exactly that, automatically, roughly 60 times every second.

2. AnimationController vs. Ticker

You may have seen AnimationController used elsewhere in Flutter — it's great for a single animation with a clear start and end, like a button fading in over 300 milliseconds. But a game doesn't have an end (until you crash). We need something that just keeps firing, indefinitely, with no built-in duration.

Analogy: think of Ticker as a heartbeat, and AnimationController as a stopwatch built on top of that heartbeat. AnimationController uses the heartbeat to count from 0% to 100% of a fixed animation and then stops. We don't want that — we just want the raw heartbeat itself, firing forever, so we can decide what to do with each beat ourselves.

To get a raw Ticker, a State class mixes in SingleTickerProviderStateMixin and calls createTicker(), passing a function that gets called on every single frame.

3. Gravity: Speed That Builds Up

Analogy: picture a snowball rolling down a hill. It doesn't instantly hit top speed — every second it rolls, it picks up a bit more speed than it had the second before. Gravity in our game works the same way: every tick, we add a small amount to the player's falling speed, and then move the player down by however fast they're currently falling. The longer they fall, the faster they fall.

Example 1: Gravity Takes Hold

Let's convert GameScreen from a StatelessWidget into a StatefulWidget, wire up a Ticker, and apply gravity to the player each tick until they land on the ground.

// Player, Obstacle, and GameBackground are unchanged from Module 4.
// GameScreen is now a StatefulWidget.

class GameScreen extends StatefulWidget {
  final GameSession session;

  const GameScreen({super.key, required this.session});

  @override
  State createState() => _GameScreenState();
}

class _GameScreenState extends State
    with SingleTickerProviderStateMixin {
  static const double gameWidth = 360;
  static const double gameHeight = 520;
  static const double gravity = 0.6;

  late final Ticker _ticker;
  late Player _player;
  double _velocityY = 0;

  GameSession get _session => widget.session;

  @override
  void initState() {
    super.initState();
    _player = Player(x: 40, y: 0);
    _ticker = createTicker(_onTick)..start();
  }

  @override
  void dispose() {
    _ticker.dispose();
    super.dispose();
  }

  void _onTick(Duration elapsed) {
    setState(_updatePhysics);
  }

  void _updatePhysics() {
    _velocityY += gravity;
    _player.y += _velocityY;

    final groundY = gameHeight - _player.size;
    if (_player.y > groundY) {
      _player.y = groundY;
      _velocityY = 0;
    }
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Game')),
      body: Center(
        child: SizedBox(
          width: gameWidth,
          height: gameHeight,
          child: ClipRect(
            child: Stack(
              children: [
                const GameBackground(),
                _player.build(),
              ],
            ),
          ),
        ),
      ),
    );
  }
}

A few things worth noticing: we swapped the fixed-size SizedBox.expand() for a fixed 360×520 game viewport — that gives us a known width and height to do physics maths against, wrapped in ClipRect so nothing draws outside it. The _updatePhysics() method runs on every tick, and it's the only place player position changes — exactly the "script" role GameSession played back in Module 3, just for physics instead of score.

4. Jumping: A Sudden Kick

Analogy: gravity builds speed gradually, but a jump is the opposite — an instant burst, like stomping a pogo stick. The moment the player taps the screen, we immediately set their falling speed to a big negative number (upward), and then just let gravity do its normal job of gradually pulling that speed back down to zero and beyond, curving them back to the ground.

Try tapping repeatedly in the panel above — each tap resets the falling speed to jumpVelocity (a big upward number), and from that point on, gravity takes back over exactly as before, curving the player back down. That's the entire "feel" of a jump-based game, in about four lines of physics.

5. Bounding-Box Collision: Do Two Boxes Touch?

Our player is drawn as an oval and the obstacle as a rectangle, but checking whether an oval and a rectangle precisely overlap is fiddly maths. Almost every 2D game cheats: it draws an invisible rectangle — a bounding box — around each entity, and just checks whether those two rectangles overlap.

Analogy: imagine each entity casts a rectangular shadow straight down onto the floor, regardless of its actual shape. Instead of comparing the complicated shapes themselves, we just check whether the two shadows overlap. It's not perfectly precise — a bit of empty space at an oval's corners might count as a "hit" — but it's fast, simple, and good enough for almost every game.

Flutter's Rect class has exactly this check built in: rectA.overlaps(rectB) returns true if the two rectangles share any space at all.

Example 3: Obstacles, Collision, and Game Over

For the final piece, let's bring the obstacle back, scroll it toward the player, recycle it (and score a point) once it passes off the left edge, and end the game the moment the player's bounding box touches the obstacle's.

class _GameScreenState extends State
    with SingleTickerProviderStateMixin {
  static const double gameWidth = 360;
  static const double gameHeight = 520;
  static const double gravity = 0.6;
  static const double jumpVelocity = -12;

  late final Ticker _ticker;
  late Player _player;
  late Obstacle _obstacle;
  double _velocityY = 0;
  bool _isGameOver = false;

  GameSession get _session => widget.session;

  @override
  void initState() {
    super.initState();
    _player = Player(x: 40, y: gameHeight - 50);
    _obstacle = Obstacle(x: gameWidth);
    _ticker = createTicker(_onTick)..start();
  }

  @override
  void dispose() {
    _ticker.dispose();
    super.dispose();
  }

  void _onTick(Duration elapsed) {
    if (_isGameOver) return;
    setState(_updatePhysics);
  }

  void _updatePhysics() {
    _velocityY += gravity;
    _player.y += _velocityY;

    final groundY = gameHeight - _player.size;
    if (_player.y > groundY) {
      _player.y = groundY;
      _velocityY = 0;
    }
    if (_player.y < 0) {
      _player.y = 0;
      _velocityY = 0;
    }

    _obstacle.x -= 3;
    if (_obstacle.x + _obstacle.width < 0) {
      _obstacle.x = gameWidth;
      _session.addPoint();
    }

    if (_checkCollision()) {
      _isGameOver = true;
      _session.loseLife();
      _ticker.stop();
    }
  }

  bool _checkCollision() {
    final playerRect = Rect.fromLTWH(_player.x, _player.y, _player.size, _player.size);
    final obstacleRect = Rect.fromLTWH(
      _obstacle.x,
      gameHeight - _obstacle.height,
      _obstacle.width,
      _obstacle.height,
    );
    return playerRect.overlaps(obstacleRect);
  }

  void _jump() {
    if (_isGameOver) return;
    setState(() {
      _velocityY = jumpVelocity;
    });
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      appBar: AppBar(title: const Text('Game')),
      body: Center(
        child: GestureDetector(
          onTap: _jump,
          child: SizedBox(
            width: gameWidth,
            height: gameHeight,
            child: ClipRect(
              child: Stack(
                children: [
                  const GameBackground(),
                  _obstacle.build(),
                  _player.build(),
                  Positioned(
                    top: 16,
                    left: 16,
                    child: Text(
                      'Score: ${_session.score}',
                      style: const TextStyle(
                        fontSize: 20,
                        color: Colors.white,
                        fontWeight: FontWeight.bold,
                        shadows: [Shadow(blurRadius: 4, color: Colors.black)],
                      ),
                    ),
                  ),
                  if (_isGameOver)
                    Positioned.fill(
                      child: Container(
                        color: Colors.black54,
                        child: Center(
                          child: Column(
                            mainAxisSize: MainAxisSize.min,
                            children: [
                              const Text(
                                'Game Over',
                                style: TextStyle(
                                  fontSize: 32,
                                  color: Colors.white,
                                  fontWeight: FontWeight.bold,
                                ),
                              ),
                              const SizedBox(height: 8),
                              Text(
                                'Score: ${_session.score}',
                                style: const TextStyle(fontSize: 20, color: Colors.white),
                              ),
                              const SizedBox(height: 24),
                              ElevatedButton(
                                onPressed: () => Navigator.pop(context),
                                child: const Text('Back to Menu'),
                              ),
                            ],
                          ),
                        ),
                      ),
                    ),
                ],
              ),
            ),
          ),
        ),
      ),
    );
  }
}

The key additions on top of Example 2: _obstacle.x -= 3 every tick scrolls it leftward; once it's fully off-screen, it's recycled back to the right edge and _session.addPoint() is called — the player "survived" it. _checkCollision() builds a Rect for the player and one for the obstacle, using their x, y, and size, then checks .overlaps(). On collision, _isGameOver flips to true, _session.loseLife() is called, the ticker stops, and a "Game Over" overlay appears with the final score and a button back to the menu.

Recap

  • Built a continuous game loop using Ticker and SingleTickerProviderStateMixin
  • Applied gravity as speed that accumulates each tick
  • Added a jump as an instant burst of upward velocity
  • Scrolled and recycled an obstacle, scoring a point each time it's survived
  • Detected collisions using bounding-box Rect.overlaps()
  • Ended the game and showed a Game Over overlay tied back to GameSession

/// Holds the game's data and rules — no widgets, no UI, just logic.
class GameSession {
  int _score = 0;
  int _lives = 3;

  int get score => _score;
  int get lives => _lives;
  bool get isGameOver => _lives <= 0;

  void addPoint() {
    _score++;
  }

  void loseLife() {
    if (_lives > 0) {
      _lives--;
    }
  }
}

/// The player character — an entity with a position and a way to draw itself.
class Player {
  double x;
  double y;
  final double size;

  Player({required this.x, required this.y, this.size = 50});

  Widget build() {
    return Positioned(
      left: x,
      top: y,
      child: CustomPaint(
        size: Size(size, size),
        painter: _PlayerPainter(),
      ),
    );
  }
}

class _PlayerPainter extends CustomPainter {
  @override
  void paint(Canvas canvas, Size size) {
    final body = Paint()..color = Colors.orange;
    canvas.drawOval(Rect.fromLTWH(0, 0, size.width, size.height), body);

    final eye = Paint()..color = Colors.black;
    canvas.drawCircle(Offset(size.width * 0.68, size.height * 0.35), 4, eye);
  }

  @override
  bool shouldRepaint(covariant CustomPainter oldDelegate) => false;
}

/// An obstacle the player has to avoid — same entity pattern as Player.
class Obstacle {
  double x;
  final double width;
  final double height;

  Obstacle({required this.x, this.width = 40, this.height = 140});

  Widget build() {
    return Positioned(
      left: x,
      bottom: 0,
      child: CustomPaint(
        size: Size(width, height),
        painter: _ObstaclePainter(),
      ),
    );
  }
}

class _ObstaclePainter extends CustomPainter {
  @override
  void paint(Canvas canvas, Size size) {
    final paint = Paint()..color = Colors.green.shade700;
    canvas.drawRect(Rect.fromLTWH(0, 0, size.width, size.height), paint);
  }

  @override
  bool shouldRepaint(covariant CustomPainter oldDelegate) => false;
}
