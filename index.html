Build a 2D Side-Scrolling Game in Flutter

A free, browser-based course that takes you from "I've never installed a dev tool before" to "I built a game engine from scratch" — no third-party game engine required. Every lesson has live, editable code running right next to the text, powered by DartPad.

No experience needed. You don't need to know Dart, Flutter, or even much programming to start. We'll build up your knowledge one module at a time.

The Roadmap

    Start with Module 1 to get your tools installed, then work through Modules 2 to 5 in order — each one builds directly on the last, ending with a complete, playable game.
