Flutter Game Tutorial

Build a 2D Side-Scrolling Game in Flutter

A free, browser-based course that takes you from "I've never installed a dev tool before" to "I built a game engine from scratch" — no third-party game engine required. Every lesson has live, editable code you can run right here in your browser using DartPad.

No experience needed. You don't need to know Dart, Flutter, or even much programming to start. We'll build up your knowledge one module at a time.

The Roadmap

  1. Module 1: Environment Setup — Installing Android Studio, the Flutter SDK, project structure, and pubspec.yaml.
  2. Module 2: The Basics — runApp, Stateless vs. Stateful widgets, layout basics, and a single-page UI.
  3. Module 3: Object-Oriented Architecture (coming soon) — Structuring Dart with OOP, separating logic from UI, and multi-page navigation.
  4. Module 4: Game Entities (coming soon) — Building the Player, Obstacles, and Background as OOP classes.
  5. Module 5: The Game Loop (coming soon) — AnimationController and Ticker, gravity, jumping, and collision detection.

Start Here

Head to Module 1 to get your tools installed and your first project set up, then move on to Module 2 to start writing real Flutter code.
